01 / METHOD

Safety grounded in
observable execution.

Harm can emerge across many locally plausible steps. HazardAuditor assembles heterogeneous traces into one behavioral representation and learns the boundary between risky content and unsafe action.

01

Observe

Capture user intent, agent reasoning, tool arguments, outputs, and environment state.

02

Normalize

Map heterogeneous computer-use systems into a shared trajectory representation.

UATE
03

Decide

Generate an evidence-grounded analysis and a deterministic safe or unsafe verdict.

analysissafe
02 / GUARDPO

Optimize the decision,
not rationale length.

GuardPO turns deterministic verdict outcomes into batch-centered advantages, applies clipped token-level importance weighting, and normalizes rationale and verdict regions separately.

04 / INFERENCE

One trajectory in.
One auditable verdict out.

The public API reproduces the training prompt, preserves the first 16,000 prompt tokens, disables thinking mode, and uses deterministic generation.

Python 
import json
from hazard_auditor import HazardAuditor

with open("examples/trajectory.json") as file:
    trajectory = json.load(file)["content"]

auditor = HazardAuditor.from_pretrained(
    "Yunhao-Feng/HazardAuditor"
)
result = auditor.audit(trajectory)

print(result.analysis)
print(result.label)
